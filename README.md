# IoT Weather Station Project

CS335: Internet of Things - Fall 2024
Class: BESE-12AB

## Project Overview
An IoT-based Weather Station that monitors temperature, humidity, pressure, and rain status. The system uses ThingSpeak for data visualization and includes ML-based analytics.

## Project Structure
- /circuit - Circuit designs and Tinkercad files
- /src - Source code for data collection and analysis
- /docs - Project documentation
- /data - Datasets for analysis
